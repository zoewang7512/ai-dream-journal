# 畫面規格

## Metadata

- 功能：夢境數據分析看板（頁面二：獨立夢境數據統計看板）
- 畫面：分析看板總覽
- 狀態：mockup 已核准，變體已選定（見 `mockup-decision-頁面二數據看板.md`）

## 目的

讓使用者一眼看到累積夢境紀錄的情緒趨勢與主題傾向，而不必一篇篇翻閱。

## 版面配置

- 主要區域：四個圖表區塊——情緒趨勢折線圖、關鍵字文字雲、夢境紀錄月曆熱力圖、情緒分佈圓餅圖＋統計摘要卡。
- 次要區域：統計摘要（總完成篇數、平均字數、記錄天數）。
- 導覽：主 Nav（既有，不變更）＋ 月曆熱力圖的月份切換（上一月／下一月）。
- 動作：無破壞性動作，純唯讀視覺化；空狀態時提供「前往寫日記」CTA。

## 狀態

| 狀態 | 必要行為 | 空狀態／錯誤文案 | 驗證方式 |
|---|---|---|---|
| 有資料 | 四個圖表區塊皆正常渲染，反映 `status=completed` 的資料 | — | 螢幕截圖 |
| 資料極少（1-2 篇邊界） | 折線圖優雅顯示單點而非報錯；文字雲/熱力圖/圓餅圖以現有資料正常渲染 | — | 螢幕截圖 |
| 空狀態（0 篇完成） | 四個圖表區塊都各自顯示一致的引導文案＋「前往寫日記」CTA，而非空白圖表或報錯 | 「還沒有已完成的夢境紀錄，去寫下第一篇吧。」 | 螢幕截圖 |
| 載入中 | 不適用（純前端同步計算 LocalStorage，無網路等待） | 不適用 | 不適用 |
| 錯誤 | LocalStorage 資料格式異常時，該圖表區塊優雅降級顯示錯誤提示，不影響其他區塊、不整頁白屏 | 「這個圖表暫時無法顯示。」 | 螢幕截圖 |
| 停用 | 不適用（無可停用的互動元素） | 不適用 | 不適用 |
| 權限不足 | 不適用（無身分驗證/權限機制） | 不適用 | 不適用 |
| 行動裝置版 | 版型改為單欄堆疊，圖表區塊各自全寬 | — | 螢幕截圖 |

## 互動

| 動作 | 觸發條件 | 結果 | 失敗情境 |
|---|---|---|---|
| 切換月曆熱力圖月份 | 點擊「上一月／下一月」 | 更新該月每日是否有紀錄的顯示，不影響其他三個圖表 | 無更多月份資料時可切換到空白月份（正常，非錯誤） |
| 前往寫日記 | 空狀態下點擊 CTA | 導覽到頁面一（寫日記/看日記） | 無 |

## 設計系統對照

- 用到的既有 design token：`color-primary-*`、`color-grey-*`、`color-success-*`、`color-danger-*`、`color-warning-*`、`color-info-*`（情緒圓餅圖／熱力圖強度可能需要多色階區分）、`font-family-hand`、`font-family-serif`、`space-*`、`radius-lg/md/sm/pill`、`shadow-card`。
- 用到的既有元件：`Card`、`Button`（ghost，月曆月份切換／CTA）、`Nav`（既有，不變更）。
- 本畫面新做的元件：無新增 React 元件；四個圖表本身在 mockup 階段以手刻 SVG／CSS（折線用 SVG polyline、文字雲用不同字級的文字排列、熱力圖用 CSS grid 色塊、圓餅圖用 `conic-gradient`）呈現版面配置，**不引入任何圖表函式庫**。實際圖表函式庫選型（如 Chart.js／Recharts／D3 等）留給「夢境數據分析看板」Epic 的實作任務卡另外決策，需列 2-3 個選項供人工選擇，不在本任務範圍內。

## 視覺驗收標準

- 文字在手機版與桌面版都不會被截斷。
- 主要動作清楚明確。
- 錯誤與空狀態明確呈現，四個區塊的空狀態文案與 CTA 風格一致。
- **色彩、字體、間距、圓角、陰影一律取自 `design-system.md` 的 design token，沒有硬寫的一次性數值。**
- **重複使用元件庫 inventory 裡的既有元件；任何新做的元件都依既有 token 與風格製作，且已登記回 inventory。**
