## 問題

五個核心功能 Epic（專案設置、核心夢境日記記錄、AI 夢境分析與圖像生成引擎、夢境數據分析看板、資料備份與匯出匯入）皆已完成，產品功能面已可用。但目前：(1) Nav 列沒有品牌識別（無 logo），備份設定的齒輪圖示樣式需要微調；(2) 沒有頁尾；(3) 專案只存在本機，沒有推上 GitHub、沒有部署上線，使用者無法把連結分享給其他人。

## 使用者

專案擁有者本人（zoewang7512）；上線後的終端使用者（親朋好友）。

## 目標

- Nav 列左側加上品牌 logo，齒輪圖示改為無外圈的簡潔樣式。
- 加上極簡頁尾（版權字樣 + GitHub 連結）。
- 推上一個新的 public GitHub repo。
- 部署到 Vercel（repo 已有 `vercel.json` 設定），取得可分享的正式連結。

## 非目標

- 多語系（i18n）：使用者已決定擱置，需要更多時間評估 AI 分析結果跨語言的資料一致性問題，不在本 Epic 範圍。
- 新手引導教學：使用者已決定不做，維持現有空狀態提示文案即可。
- 自訂網域：預設先用 Vercel 配發的網域，除非之後另外提出需求。

## 功能需求

- WHEN 任何頁面載入 THE SYSTEM SHALL 在 Nav 列左側顯示品牌 logo 圖片。
- WHEN 使用者點擊備份設定圖示 THE SYSTEM SHALL 開啟備份設定 Modal，圖示本身不得有外圈圓形邊框或背景色。
- WHEN 任何頁面載入 THE SYSTEM SHALL 在頁面底部顯示頁尾，內容為版權字樣與 GitHub repo 連結。
- WHEN 使用者點擊頁尾的 GitHub 連結 THE SYSTEM SHALL 在新分頁開啟對應的 GitHub repo 頁面。
